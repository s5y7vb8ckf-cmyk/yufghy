MILO CASHIER V13 - زر تحميل التطبيق من المتصفح

1. ارفع جميع الملفات والمجلدات على GitHub Pages، وليس الملف ZIP نفسه.
2. افتح رابط الموقع HTTPS في أحدث Chrome أو Microsoft Edge.
3. ستجد زر «تحميل تطبيق ميلو كاشير» في شاشة تسجيل الدخول، بالإضافة إلى زر التثبيت في الشريط العلوي بعد الدخول.
4. عند إتاحة مطالبة التثبيت من المتصفح، يفتح الزر مربع تثبيت التطبيق الأصلي في المتصفح (PWA). لا يوجد ملف EXE مستقل.
5. إن لم يوفّر المتصفح نافذة التثبيت، يعرض الزر خطوات التثبيت اليدوية من قائمته.
6. لإزالة أيقونة قديمة، احذف التطبيق القديم من chrome://apps أو edge://apps ثم أعد تثبيته.

ملاحظة: تثبيت PWA يعتمد على استيفاء شروط المتصفح ونظام التشغيل؛ لا يمكن إجبار المتصفح على عرض مربع التثبيت. إضافة الأيقونة إلى سطح المكتب يحددها المتصفح وخيارات المستخدم.
تسجيل الدخول القديم وملفات المبيعات والفواتير لم تُعدّل. التغيير مقتصر على زر التثبيت، ملف pwa.js، نمط الواجهة وتحديث إصدار الخدمة المخزنة.
