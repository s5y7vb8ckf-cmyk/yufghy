MILO CASHIER — إصلاح طباعة فاتورة الزبون وQR

يجب تحديث ملفي الكاشير وبرنامج Windows معًا.

- فاتورة الزبون: الشعار بالأعلى إذا كان محفوظًا، ثم جدول الأصناف، ثم الإجمالي، ثم QR الضريبي إن كان مولّدًا في الكاشير، وأخيرًا شكرًا لزيارتكم.
- تذكرة المطبخ: مستقلة بدون أسعار أو QR؛ عبارة نهاية تذكرة المطبخ تظهر فيها فقط.
- لن يُطبع QR إذا كان الرقم الضريبي غير صالح أو خيار QR معطلًا أو لم ينتج الكاشير QR.
- هذه التعديلات لا تمثل اعتمادًا أو تكاملًا رسميًا مع ZATCA. يلزم اختبار صحة البيانات ومتطلبات المرحلة الثانية بشكل مستقل.

خطوات: ارفع ملفات الكاشير الجديدة إلى نفس استضافة الموقع، حدث المتصفح تحديثًا قويًا، وأعد بناء برنامج Windows من مجلد MILO_Print_Bridge ثم أغلق القديم وشغّل الجديد.
أمر البناء داخل مجلد المشروع:
set "TEMP=%LOCALAPPDATA%\Temp" && set "TMP=%LOCALAPPDATA%\Temp" && dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist
