MILO CASHIER V13 — الاعتماد على زر التثبيت الأصلي للمتصفح فقط

هذه النسخة تلغي زر تحميل التطبيق من صفحة تسجيل الدخول ومن شريط الكاشير، وتمنع ظهور الشريط الإعلاني الداخلي للتثبيت.
كما أزيلت بطاقة تثبيت التطبيق من الإعدادات إن وجدت.

لا تتغير طريقة تسجيل الدخول القديمة، أو وظائف الفواتير والمبيعات والطباعة.
يظل ملف manifest وأيقونات سطح المكتب وService Worker موجودة لدعم تثبيت PWA من Chrome أو Edge.

ارفع جميع محتويات الملف المضغوط إلى جذر مستودع GitHub Pages، وانتظر نشرها ثم حدث الصفحة بقوة Ctrl+Shift+R.
في حال ظهور النسخة القديمة، أغلق التطبيق المثبت وأعد فتح رابط الموقع بالمتصفح، أو امسح بيانات الموقع والكاش بحذر (قد يؤثر مسح بيانات الموقع على البيانات المحلية غير المتزامنة).
ظهور زر التثبيت في شريط عنوان المتصفح يعتمد على شروط المتصفح، ولا يمكن فرضه من الموقع.
