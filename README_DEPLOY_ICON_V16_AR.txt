MILO CASHIER V13 — إصلاح اختفاء الأيقونات على GitHub Pages و Vercel (الإصدار 16)

- تم تغيير أسماء أيقونات التطبيق إلى milo-v16 لمنع رجوع أيقونات قديمة من الذاكرة المؤقتة.
- تمت إضافة manifest-v16.webmanifest وتحديث روابط HTML و favicon-v16.ico.
- تمت إضافة صورة احتياطية مدمجة داخل HTML: إذا تعذر تحميل الشعار من مجلد icons يظهر الشعار حتى على استضافة تعيد 404 للملف.
- تحديث sw.js ليخزن الملفات المتاحة بصورة مستقلة ولا يفشل تثبيته عند تعطل مورد واحد.
- إضافة .nojekyll لـ GitHub Pages و vercel.json لتحديد أنواع الملفات والكاش.

طريقة النشر:
1. فك ZIP وارفع *محتوياته* إلى جذر المستودع الذي ينشر منه الموقع (وليس ملف ZIP نفسه، ولا مجلدًا إضافيًا).
2. في GitHub Pages: Settings > Pages وتأكد من الفرع والمجلد الصحيح (root أو docs).
3. في Vercel: Framework Preset = Other، و Root Directory = المجلد الذي يحتوي index.html، و Output Directory اتركه فارغًا للموقع الثابت.
4. بعد النشر تأكد أن الرابط التالي يعرض صورة: https://YOUR_DOMAIN/icons/milo-v16-192.png
5. احذف تثبيت الموقع القديم من Edge/Chrome، ومن أدوات المطور Application > Storage اضغط Clear site data، ثم ثبت من جديد.
6. لا تنسَ أن مستخدمي GitHub Pages قد يستخدمون مسار /REPOSITORY/؛ جميع الروابط هنا نسبية وتعمل مع هذا المسار.

ملاحظة: الأيقونات داخل ملف ZIP سليمة. لم يتوفر رابط موقع منشور لاختباره حيًا.
