MILO CASHIER — تحديث رابط Google Apps Script

تم تحديث رابط الاتصال في app.js و customer-order.html إلى رابط Apps Script الذي زوّدنا به المستخدم.
لم يتم تغيير Code.gs أو منطق الفواتير أو الطباعة أو إتمام الطلب.

قبل التشغيل: تأكد أن النسخة المنشورة على نفس الرابط تحتوي على Code.gs المرفق، وشغّل setup عند الحاجة لتجهيز CustomerOrders ثم أعد نشر الإصدار. تغيير الرابط في الموقع لا يحدّث Apps Script الموجود على Google تلقائيًا.

صفحة طلبات الزبون تُنشر مع ملفات موقع الكاشير ويصدر رابطها من الإعدادات؛ رابط Apps Script ليس نفسه رابط صفحة المنتجات.
احفظ نسخة احتياطية واختبر طلبًا واحدًا مكتملًا وطباعة الفاتورة قبل الاستخدام الفعلي.
