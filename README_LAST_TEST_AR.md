# MILO CASHIER 3.6.0 — التجربة الأخيرة للطباعة المباشرة

هذه نسخة تجريبية للطباعة الحرارية بـ WebUSB أو Web Serial (ESC/POS) من Chrome/Edge. تبقى بقية صفحات الكاشير وGoogle Sheets كما هي في نسخة المتصفح 3.4.8.

1. انشر محتويات ZIP على GitHub Pages عبر HTTPS (ليس من ملف HTML محلي).
2. افتح **الإعدادات** ثم **تجربة الطباعة الحرارية المباشرة**.
3. اضغط «توصيل USB» أو «توصيل Serial» ومنح إذن المتصفح للطابعة. **USB يتطلب طابعة USB ESC/POS لها Bulk OUT interface قابلة للمطالبة من المتصفح؛ بعض تعريفات Windows تمنع الاتصال.** Serial baud 9600 افتراضيًا.
4. اضغط «طباعة تجربة» قبل تفعيل الخيار.
5. إذا نجحت، فعّل «الطباعة المباشرة التجريبية». إذا لم تنجح، أوقف الخيار واستخدم طباعة المتصفح.

- الفاتورة تُرسم كصورة عربية وESC/POS raster على شرائح، بلا فواصل صفحات؛ قص واحد في نهاية كل مستند. المطبخ مستند مستقل يُقص بمفرده.
- لا تظهر رؤوس/تذييلات Chrome أو Edge. لا تحتاج إلى Python.
- هذه تجربة؛ بعض طابعات ESC/POS تحتاج أوامر قص مختلفة أو إعداد USB/Serial خاص. لا يوجد ضمان لطباعة فاتورة طويلة جدًا بدون حد مادي في الطابعة (الذاكرة/طول البكرة).
- لا تحفظ إذن المنفذ بين تحديثات المتصفح كلها؛ أعد الاتصال إذا احتجت. **هذا إصدار تجريبي وليس للاستخدام المالي المباشر قبل التحقق من QR والتحرير الضريبي على الطابعة الفعلية.**
- لم يتم إرسال فاتورة طباعة قبل اعتماد البيع بنجاح بالخادم.


## تحديث 3.6.1 — الفراغ في بداية فاتورة الطباعة المباشرة
- إزالة هامش الرسم العلوي الثابت.
- قص صفوف البكسلات البيضاء الأولى قبل إرسال الصورة الحرارية للطابعة.
- تقليل تغذية نهاية الإيصال من ثلاثة أسطر إلى سطر واحد قبل القص، لأن التغذية الزائدة بعد الفاتورة قد تظهر قبل الإيصال التالي.
- هذه التعديلات تخص الطباعة المباشرة WebUSB/Web Serial، وليست طباعة المتصفح العادية.
- إذا بقي الفراغ، فقد يكون من إعدادات الطابعة الميكانيكية أو تعريفها.


## 3.6.2 — تكبير خط الطباعة المباشرة وتقليل الفراغات
- زادت أحجام خطوط عنوان الفاتورة والأصناف والأسعار والإجمالي مع زيادة المساحة القابلة للطباعة عبر تقليل الهامش الجانبي.
- خُفض ارتفاع السطور والمسافات الثابتة بين أقسام الفاتورة، وأزيلت صفوف الأبيض قبل أول سطر مطبوع.
- تُقسم الكلمات الطويلة إلى أسطر بدلاً من ضغط خطها لتناسب عرض الورقة.
- المراجعة تخص مسار WebUSB / Web Serial المباشر فقط. إذا استمر الفراغ رغم قص الصفوف البيضاء، فهو غالبًا تغذية ابتدائية داخل إعدادات الطابعة أو رول الطابعة نفسه؛ لا يمكن إزالته من JavaScript وحده.
- اختبر أولاً عبر زر طباعة تجربة قبل استخدام البيع الحقيقي.
